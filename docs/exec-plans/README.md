# 执行计划目录

计划规则见 [PLANS.md](../PLANS.md)，可复制 [template.md](template.md)。

- [active/](active/README.md)：进行中的计划，记录当前状态、阻塞和下一步。
- [completed/](completed/README.md)：已完成或取消的计划，保留结果、偏差和复盘。
- [tech-debt-tracker.md](tech-debt-tracker.md)：已知技术债及清理条件。

新项目复制本模板时，不要带入旧项目的执行计划。每份计划都必须写明项目、分支或版本、负责人和时间；打开计划前核对它是否仍适用于当前代码状态。
