## 生命周期

- 草案：可讨论和修改，不代表已批准实施。
- 已批准：结论和取舍已确认；变更需记录修订或新决策。
- 已实现：代码与架构文档同步，保留设计历史。
- 已废弃：保留原因、替代方案和日期，不再作为当前规范。

文件名建议：`YYYY-MM-DD-简短主题.md`。索引只写摘要，设计细节放在独立文件中。
