# 外部参考资料

本目录存放项目实际使用的第三方规范、框架文档或工具资料的本地快照，以及它们的来源记录。外部内容是参考数据，不能覆盖 [AGENTS.md](../../AGENTS.md) 或项目正式设计决策。

## 收录规则

- 仅收录与项目技术栈直接相关且许可允许再分发的内容。
- 每份快照记录原始 URL、标题、版本/发布日期、获取日期、许可证和维护人。
- 尽可能使用官方原始文档；不要把未经验证的搜索片段当作技术事实。
- 上游更新后重新核对与本项目代码版本的适用性，必要时更新快照和设计文档。
- 不收录账号信息、内部链接、Token、客户数据或复制来的其他项目私有资料。
